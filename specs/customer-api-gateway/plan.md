# 구현 계획

사용자의 공통 규칙 작업·커밋 요청으로 진행한다.

1. 계약/주입 위치 조사 → 검증: Claude 로컬·리모트, Codex, Gemini의 진입점 확인.
2. 실패 테스트와 공통 규칙 연결 → 검증: 세션 지침 포함·master OFF·후속 메시지 비중복.
3. 회귀·타입·빌드 검증 및 커밋·브랜치 푸시 → 검증: 관련 테스트와 커밋 범위 확인.
